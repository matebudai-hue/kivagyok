# Jégtörő · Budai Máté

Budai Máté szakmai honlapja. A weboldal a `dist` mappában található, build lépés nélkül kiszolgálható statikus HTML/CSS/JavaScript.

Helyi előnézet: `python3 -m http.server 8000 --directory dist`

A honlap 13 oldalból áll. A Sites előnézet külön forrástárolóból működik, a GitHub változásai nem kerülnek automatikusan közzétételre.
